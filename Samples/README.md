# Default sample bank

WAV files dropped in this folder are copied into each build on every compile:

- VST3: `TapeBank.vst3/Contents/Resources/Samples/`
- Standalone (macOS): `TapeBank.app/Contents/Resources/Samples/`
- Standalone (Windows/Linux): `Samples/` next to the executable

The file naming convention (note mapping across C2–C6) is defined in Step 3.
